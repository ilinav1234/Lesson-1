Курсов проект по Python

Тема: Автосалон

Описание:
Това е конзолна програма за управление на автосалон.
Потребителят може да вижда всички автомобили, да добавя нови автомобили,
да търси автомобил по модел, да продава автомобил, да променя цена
и да сортира автомобилите по цена.

Файлове:
1. models.py - съдържа класовете Car и AutoSalon.
2. main.py - главният файл, от който се стартира програмата.
3. requirements.txt - информация за използваните библиотеки.
4. readme.txt - описание на проекта.

Използвани елементи:
- Класове
- Обекти
- Методи със self
- Списък list
- Речник dictionary
- Цикъл while
- Цикъл for
- Условни оператори if / else
- Обработка на грешки с try / except

Как се стартира:
Стартира се файлът main.py.
